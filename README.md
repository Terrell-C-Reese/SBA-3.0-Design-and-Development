# SBA-3.0-Design-and-Development


The project I chose to complete for this assignment was the Fylo Data Storage Component. 
Essentially, the project requirements were to make two cards, one that displays various 
buttons made from icons and the other card, which required a status bar displaying the 
amount of data left in the cloud storage. 


My approach was fairly straight-forward. I decided to make the initial cards and add 
the relevant information and assets. Then I decided to use vanilla CSS to style and place
everything in the correct spots for this project. Afterwards, I began to go through my code 
and apply bootstrap to replace the vanilla CSS. Additionally, I added the @media queries 
to work on the responsiveness of the page for both desktop and mobile usage.


The majority of issues I faced were due to careless mistakes, such as not calling the correct class 
in my CSS. The only real issue I ran into was figuring out how to apply the gradient required for the
status bar on the second card. I had to use W3Schools and a youtube video to understand how to properly
utilize the gradient feature.
